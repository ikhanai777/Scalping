# Scalping

A free, open-source scalping terminal for Binance Spot and USDⓈ-M Futures. It combines real-time
charts with order flow, calibrated buy/sell signals, and a news and sentiment feed.

The full product and technical specification is in [`docs/SPEC.md`](docs/SPEC.md).

> Not financial advice. Trading crypto, especially leveraged scalping, carries a high risk of loss.
